# Promotion kit

Paste-ready posts for qoder-claude. Everything here was written to be posted as-is, by a human, from a human account.

## Rules the copy follows

1. **State the limitation in the first third of every post.** qoder-claude needs a Qoder account, and it is not affiliated with Anthropic or Qoder. If the post hides that, the first reply becomes an accusation and the thread is dead.
2. **No superlatives.** No "revolutionary", no "game changer", no "unlimited". The project removes one specific annoyance: you keep Claude Code but the model traffic goes to another plan.
3. **No fake numbers.** Do not claim a free tier, an unlimited quota, or a benchmark that was not run.
4. **One link per post.** Site or repo, not both. The site has the install command; the repo has the code.
5. **Never post the same link in the same community twice in under two weeks.** It reads as spam and gets removed.
6. **Reply to every comment for the first two hours.** A post's rank is decided in that window.
7. **No vote/star requests.** Ever.

## Order to post

1. **r/ClaudeAI** first — smallest risk, the pain is exactly their pain. If the post lands, it gives you something to point at.
2. **Show HN**, 24–48 h later, on a weekday morning US Eastern. HN is one shot; do not burn it before the repo has a release and a screenshot.
3. **r/LocalLLaMA** after that, with the technical framing.
4. **X thread** any time — it is the one that links back to the others.
5. **dev.to** last, as the evergreen piece you can link forever.
