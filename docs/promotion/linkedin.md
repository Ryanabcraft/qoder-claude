# LinkedIn

## English

```
I kept running into the same wall: the coding assistant I like has a usage limit,
and the plan I barely use has headroom.

So instead of switching tools, I moved the model call.

qoder-claude is a small local server that speaks the Anthropic API and forwards
the traffic to Qoder. Claude Code stays exactly as it is — same interface, same
tools, same shortcuts — and the metering moves to the other plan.

What it adds beyond forwarding: failover between accounts when one hits a quota,
real credit tracking per account with a forecast of when it runs out, and a local
dashboard.

Two things I want to be upfront about: it needs a Qoder plan of your own, and it
is not affiliated with Anthropic or Qoder.

MIT, one command to install, Windows/macOS/Linux.

https://github.com/Ryanabcraft/qoder-claude
```
