# Discord communities

Read the server rules first. Many coding servers have a `#showcase` or `#projects` channel and a "no DM advertising" rule — post there, once, and stay for the replies.

## English

```
Built a small bridge that runs Claude Code against Qoder models.

It is a local server on 127.0.0.1:8787 that speaks the Anthropic Messages API, so
Claude Code keeps its tools, MCP servers and slash commands — only the model call
changes. It also fails over between Qoder accounts when one hits a quota, and has
a local dashboard with real credits and a burn forecast.

Needs a Qoder plan of your own; not affiliated with Anthropic or Qoder. MIT.

https://github.com/Ryanabcraft/qoder-claude

Happy to answer questions about the transport or the failover logic.
```

## Notes for the submitter

- One post per server. Do not repost after a week because "nobody saw it".
- Do not DM people who react. Answer in the channel.
- If the server has a link channel separate from the showcase channel, put the link there and the text in the showcase, or just skip it.
